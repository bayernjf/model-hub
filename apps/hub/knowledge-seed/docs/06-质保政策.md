# 质保政策

雪峰保温杯自签收次日零时起提供 12 个月有限质保，质保主体为杭州雪峰户外用品有限公司。

质保范围（非人为原因导致的功能性故障）：

- 真空层失效：正常使用下保温性能明显低于标称值，经客服检测确认后换新。
- 密封缺陷：杯盖密封圈在无外力损坏情况下出现漏水，免费更换密封圈组件。
- 工艺缺陷：焊接处渗漏、旋盖螺纹滑牙等制造问题，凭订单记录换新。

不在质保范围的情形：跌落或撞击造成的凹陷、外层喷涂磨损、自行拆卸改装、未按清洁指南使用导致的腐蚀、密封圈等易损件的正常老化、外观划痕与色差。

质保流程：在订单页发起售后或联系客服，提供订单号与故障视频；检测确认属于质保范围的，7 个工作日内发出换新件，往返运费由公司承担。易损件（密封圈、杯盖）可单独购买，密封圈建议每 12 个月更换一次。

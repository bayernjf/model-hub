# 保温性能参数

雪峰保温杯的保温与保冷性能按国标 GB/T 29607 方法在 20±2℃ 环境测得，以下为出厂标称值。

保温效果（注入 95℃ 热水，6 小时后测温）：

- XF-350 轻行款：6 小时 ≥ 72℃，12 小时 ≥ 58℃。
- XF-500 标准款：6 小时 ≥ 74℃，12 小时 ≥ 60℃。
- XF-750 远征款：6 小时 ≥ 76℃，12 小时 ≥ 63℃，24 小时仍可保持在 45℃ 以上。

保冷效果（注入 4℃ 冷水，6 小时后测温）：全系列 6 小时 ≤ 10℃。

标称值基于实验室环境，实际表现受环境温度、初始水温、开合频次影响。装入碳酸饮料、干冰或液态氮会导致内部压力异常升高，属于明确禁止的使用方式。

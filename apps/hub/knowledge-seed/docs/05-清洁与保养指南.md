# 清洁与保养指南

正确清洁与保养直接影响保温寿命和密封性能，请按以下方式维护。

首次使用前：用温水搭配中性食品级洗涤剂冲洗内胆与杯盖，再用清水漂净、开盖晾干，不要带盖密闭存放。

日常清洗：

1. 每次使用后尽快冲洗，避免饮品长时间残留产生异味。
2. 杯盖与密封圈建议每周至少整体拆卸清洗一次，缝隙处可用软毛刷处理。
3. 内胆可用小苏打（碳酸氢钠）温水浸泡 30 分钟去除茶渍或咖啡渍。
4. 清洗后必须完全晾干再收纳，长期带水密闭会产生霉点。

禁止事项：不得使用钢丝球或含研磨颗粒的清洁剂；不得整杯放入洗碗机（高压喷淋与高温烘干会破坏密封圈和外层喷涂）；不得进微波炉、烤箱或消毒柜高温层；不得使用含氯漂白剂，氯离子会破坏不锈钢钝化膜并引发点蚀。

长期不用时，保持杯盖松开状态，与备用密封圈一同存放于干燥处，避开阳光直射。
